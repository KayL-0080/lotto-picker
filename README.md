## 🌟 5가지 추천 유형(Type) 및 통계적 근거

| 유형 | 명칭 | 통계적 근거 및 특징 |
| :---: | :--- | :--- |
| **Type 1** | **🔥 고빈도 모멘텀형**<br>(Hot Momentum) | **추세 추종형**: 최근 10~30회차 다출현 번호와 역대 누적 최다 빈출 번호의 가중 출현율을 결합하여, 현재 당첨 상승 흐름(모멘텀)을 타고 있는 핫 넘버 중심 조합 |
| **Type 2** | **❄️ 미출현 주기 반등형**<br>(Cold & Mean Reversion) | **평균 회귀형**: '큰 수의 법칙'에 따라 고유 평균 출현 주기를 초과한 장기 미출현 번호(30주 미출 5번, 19주 미출 27번 등)와 직전 회차 이월수를 배합한 반등 노림수 조합 |
| **Type 3** | **⚖️ 황금 균형 통계형**<br>(Golden Balance) | **정규분포 최적형**: 역대 1등 당첨 번호의 80% 이상이 수렴하는 **홀짝 3:3, 고저(1~22/23~45) 3:3, 총합 120~160(평균 138 전후)**의 이상적인 수학적 균형 조합 |
| **Type 4** | **🔗 연번 & 동끝수 실전 패턴형**<br>(Consecutive & End-digit) | **실전 상관관계형**: 실제 당첨의 약 60%에서 발생하는 **1쌍의 연속번호(연번)**와 70% 이상에서 발생하는 **끝자리 일치(동끝수)** 특성을 반영한 실전 조합 |
| **Type 5** | **🤖 AI 동반출현 & 복잡도 최적화형**<br>(AI Synergy & AC Optimization) | **하이브리드 시너지형**: 45×45 궁합수(동반 출현) 매트릭스 점수를 극대화하고, 로또 난수 산포도 지표인 **AC값(산술 복잡도) 7~10**을 최적화한 최고 기대치 조합 |

## 🚀 실행 방법

### 방법 1. 더블 클릭 한 번으로 실행 (가장 간편)
폴더 내의 **`run.bat`** 파일을 더블 클릭하세요.
- 자동으로 최신 회차를 확인/동기화합니다.
- 콘솔 창에 5가지 유형과 추천 번호, 상세 지표를 출력합니다.
- 웹 브라우저에서 아름다운 시각화 대시보드(`index.html`)가 자동으로 열립니다.

### 방법 2. 파이썬 콘솔 명령어로 실행
```powershell
# 콘솔 분석 및 index.html 생성
python main.py

# 또는 실시간 웹서버 구동 (브라우저에서 [새로고침 / 재추첨] 버튼 지원)
python web_server.py
```
> 브라우저 접속 주소: `http://localhost:8088`
